# Memória

## contract/
Registro factual da execução corrente: decisões, evidências, tentativas e resultados.

## role/
Padrões de trabalho ligados a um papel. Não é memória institucional.

## institutional/candidates/
Aprendizados propostos após retrospectiva. Não são verdade canônica.

## institutional/promoted/
Somente aprendizados validados e promovidos por regra explícita.

Regra: um agente nunca transforma a própria opinião diretamente em memória institucional.
