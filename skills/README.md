# Skills

Uma skill adiciona especialização a um papel sem assumir governança do kernel.

Exemplos futuros:
- `marketing/brand-identity`
- `marketing/slogans`
- `marketing/campaigns`
- `marketing/video`
- `engineering/frontend`
- `engineering/backend`
- `engineering/security`
- `domains/regulated-program`

Contrato mínimo de uma skill:
1. domínio e objetivo;
2. quando carregar;
3. entradas necessárias;
4. conhecimento/regras;
5. ferramentas permitidas;
6. critérios de qualidade;
7. limites e quando escalar;
8. versão e evidência de atualização.
