# Morrow

Codinome de laboratório para um kernel autônomo de execução de contratos de software.

## Estado

**Fase 0 — extração controlada.** Este repositório ainda não é produto, SaaS ou plataforma. O objetivo inicial é isolar e reproduzir, fora de qualquer produto de origem, o mecanismo de trabalho autônomo por contrato, papéis, revisão, prova e aprendizado.

## Princípios

1. O contrato define o destino; o mapa define a rota.
2. Papel não é modelo. Um papel pode ser executado por qualquer provedor compatível.
3. Skills fornecem especialização; não governam o kernel.
4. Evidência supera declaração. Gate verde não substitui critério de contrato.
5. Aprendizado institucional só nasce após validação e promoção.
6. Nenhum segredo, dado de cliente ou conhecimento proprietário de produto de origem entra aqui.
7. A extração não modifica os repositórios de origem.

## Primeira prova

O primeiro marco será executar um contrato pequeno de software do começo ao fim e medir quantas intervenções humanas foram necessárias.
