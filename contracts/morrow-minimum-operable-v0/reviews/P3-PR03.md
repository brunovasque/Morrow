## Passe de Security Reviewer

| ataque/erro | defesa comprovada |
|---|---|
| dispatch injeta comando, PATH, perfil ou API | comando/ambiente são opções do runtime capturadas no construtor; a invocação não possui esses campos |
| ambiente usa caixa alternativa para esconder API | comparação é case-insensitive e recusa antes de abrir terminal |
| pipes são promovidos a terminal | descriptor completo é exigido no construtor, antes de auth/spawn |
| auth status é ausente, negativo ou falso | exit não zero, timeout ou ausência da linha positiva exata impede a sessão principal; “Not logged in using ChatGPT” com exit 0 tem contraprova |
| prompt aparece em evento estruturado | índice final é validado e substituído por `[REDACTED]` no start event |
| caller muda args/índices após `start()` | manager destaca request, workspace, args, índices e env antes do primeiro `await` |
| caller muda prompt/identidades/workspace durante auth | adapter destaca toda a invocação antes do primeiro `await`; a contraprova muta o objeto e observa somente os valores originais |
| resposta do agente forja linhas de metadata | parser usa somente header entre delimitadores; fixture emite provider hostil depois e não altera resultado |
| VT redraw/wrap corrompe prova | normalizador remove controles; versão exige semver e cwd compara texto compactado |
| probe aceita apenas o eco do próprio prompt | marker precisa aparecer ao menos duas vezes e há evento real anterior à resolução |
| prompt iniciado por `--` vira flag da CLI | terminador de opções `--` é obrigatório imediatamente antes do argumento sensível |
| prompt excede o envelope do launcher | encoder compartilhado mede o spec completo antes de auth e falha sem criar sessão |
| credencial entra em prompt/log | nenhum arquivo/token é lido; somente status público da CLI; prompt de prova é não sensível |

## Achados e resolução

A implementação e as revisões adversariais local/remota encontraram doze pontos antes do head final:

1. `codex exec -` aguardava EOF que ConPTY não entregava: a execução passou a usar o argumento final medido pelo CLI, com redaction específica no evento;
2. o primeiro probe de cwd ficou vermelho porque o terminal quebrou caminho longo na coluna 80: o comparador agora normaliza VT/wrap sem relaxar o caminho esperado;
3. uma contagem simples aceitava o marker presente só no eco do prompt: a prova exige prompt e resposta, além de output anterior à conclusão;
4. request/índices continuavam mutáveis durante o start assíncrono: o manager cria snapshot destacado antes do primeiro await;
5. comando/env por invocação permitiriam rebind da instalação ou perfil: ambos pertencem agora ao adapter construído pelo runtime e são capturados uma vez;
6. chaves de ambiente no Windows podiam usar caixa alternativa: a recusa API foi tornada case-insensitive;
7. metadata podia ser encontrada na resposta do agente: o parser foi limitado ao header oficial e exige provider/approval/sandbox exatos;
8. redraw VT duplicou o prefixo do banner e produziu versão inválida: o parser exige semver e a fixture reproduz a duplicação;
9. a invocação permanecia mutável durante o preflight assíncrono: o adapter agora destaca prompt, identidades e workspace antes do primeiro `await`, e a contraprova tenta rebind durante auth;
10. a busca por substring no status aceitaria uma frase negativa que contivesse “Logged in using ChatGPT” se o processo retornasse exit 0: o preflight agora exige a linha positiva exata e a fixture reproduz o falso positivo;
11. comentário remoto P1 `3890154247`: prompt iniciado por opção podia habilitar uma flag perigosa antes da checagem de metadata; `--` agora encerra as opções e a fixture o exige;
12. comentário remoto P2 `3890154252`: prompt longo podia estourar o spec de 24.000 caracteres e ser mascarado por `terminal_input_closed`; o encoder compartilhado recusa o envelope antes de auth e a contraprova observa zero sessões.
