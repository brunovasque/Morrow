## Passe de Security Reviewer

| ataque/erro | defesa comprovada |
|---|---|
| sender id escrito por atacante | identidade precisa coincidir com peer autenticado e credential verificada |
| mensagem para outra instância | destinatário precisa coincidir com identidade local |
| replay por message id/nonce | `REPLAY_DETECTED` |
| replay/out-of-order com novo nonce | sequence menor/igual é `OUT_OF_ORDER` |
| mensagem velha/futura/TTL abusivo | expiry, clock skew e TTL máximo validados |
| autorização fabricada | decision id, expiry e conjunto de scopes precisam coincidir com decisão já verificada |
| dispatch fora de contrato/target/capability | scopes derivados do body são obrigatórios |
| comando/script/segredo bruto | body estrito aceita somente work-spec ref + SHA-256; campo extra é recusado |
| workspace compartilhado ou path livre | somente workspace id opaco + `isolation: dedicated`; id nunca é path |
| downgrade de versão | somente maior versão exatamente compartilhada; sem compatibilidade presumida |
| mudança depois do gate | decoder devolve cópia profundamente congelada |
| payload/JSON ambíguo | limite de 256 KiB e member names duplicados recusados antes do decoder |
