# Review de implementação — P0-PR03

## Objetivo verificado

Provar um reconciliador que lê o pacote contratual e o estado Git e retorna a única próxima ação autorizada, bloqueando qualquer divergência.

## Implementação revisada

- `src/contract-reconciler.ts` lê `CONTRACT.md`, `PRS.md`, `LIVE_STATUS.md` e `EVIDENCE.md`;
- captura branch, HEAD, limpeza da árvore e ancestralidade do baseline por processos Git sem shell;
- exige estado contratual pronto, PR ativa conhecida, evidência para unidades provadas e dependências provadas;
- bloqueia PR duplicada, branch inesperada, baseline divergente, árvore suja e ação humana divergente;
- `npm run contract:reconcile` expõe a projeção mecânica para uma nova aba ou operador.

## Contraprovas

| cenário | resultado |
|---|---|
| pacote pronto, dependências verdes e Git limpo | libera P0-PR03 e a ação exata |
| `next_authorized_action` diferente | bloqueia `live_action_mismatch` |
| dependência pendente, árvore suja e branch errada | bloqueia cada causa explicitamente |
| identificador de PR duplicado | bloqueia `duplicate_pr_id` |
| baseline P1 incompleto | não libera P2 |
| campo obrigatório ausente no pacote | recusa leitura do pacote |

## Provas executadas

- `npm test` — 31/31;
- `npm run contract:reconcile` em árvore limpa — `READY_FOR_EXECUTION`, `P0-PR03`, `START_P0_PR03_RECONCILER`;
- `git diff --check` — verde.

## Conclusão

`P0-PR03: PROVEN`. O reconciliador não substitui os futuros gates de Worker/dispatch; ele impede que uma nova aba ou agente avance sem uma rota comprovada. Próxima unidade: `P2-PR01`.
